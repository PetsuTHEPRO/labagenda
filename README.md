# LabAgenda — Front-end demonstrativo

Abra `index.html` no navegador (ou use Live Server no VS Code).

Rotas:
- `#/` página principal
- `#/estudante`
- `#/coordenador`
- `#/admin`

CDNs: Bootstrap 5, Bootstrap Icons, GSAP/ScrollTrigger e Google Fonts.

Tudo é simulado: não há backend, autenticação ou banco de dados.
